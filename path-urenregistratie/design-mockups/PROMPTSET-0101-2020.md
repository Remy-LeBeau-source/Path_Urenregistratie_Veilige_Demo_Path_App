# Promptset 0101–2020

Alle beelden zijn gemaakt met de ingebouwde ImageGen-route als high-fidelity desktop-UI op 1536×1024. Gedeelde randvoorwaarden: Path Consultancy, september 2026, nachtblauw + bos/salie-groen + warm amber + gebroken wit, correcte Nederlandse interface, medewerker ziet geen facturen, Backoffice neemt na indienen over, en ieder pakket bevat een medewerker- en beheerdersbeeld.

## Richtingen

1. `0101 Path Panorama` — warm landschappelijk maandpad en aandachtspaneel.
2. `0202 Path Ledger` — editorial administratief dagboek met strakke regels.
3. `0303 Path Flowline` — continue proceslijn door maand en werkvoorraad.
4. `0404 Path Glasshouse` — architectonische transparante lagen.
5. `0505 Path Atelier` — tactiel papier en menselijke illustratie.
6. `0606 Path Signal` — compacte operationele signalen.
7. `0707 Path Orbit` — radiale workspace zonder klassieke zijbalk of tabel.
8. `0808 Path Command Deck` — donker commandopalet en live queues.
9. `0909 Path Calendar Canvas` — kalender als primaire interactieruimte.
10. `1010 Path Kanban` — proceskolommen en verplaatsbare dossiers.
11. `1111 Path Inbox` — conversatie- en taakgestuurde case-inbox.
12. `1212 Path Dossier Desk` — digitaal bureau met werkmappen en stempels.
13. `1313 Path Metro` — workflow als metrolijnen en stations.
14. `1414 Path Bento Space` — asymmetrisch ruimtelijk tegelcanvas.
15. `1515 Path Weekbook` — bladerbaar week- en dossierboek.
16. `1616 Path Companion` — mobiel-eerst invoeren met supervisorcockpit.
17. `1717 Path Constellation` — relationele kaart van dagen, mensen en fasen.
18. `1818 Path Monolith` — Swiss/Brutalist typografisch systeem.
19. `1919 Path Storyline` — maand en dossier als narratieve hoofdstukken.
20. `2020 Path Adaptive` — Zakelijk/Menselijk en Licht/Donker als live voorkeurassen.
