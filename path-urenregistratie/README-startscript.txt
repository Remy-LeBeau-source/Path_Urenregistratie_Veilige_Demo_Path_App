Path lokale startscript

Gebruik:
1. Dubbelklik op start-path-app.cmd.
2. De app opent op http://localhost:8000/.
3. Laat het PHP-servervenster open zolang je werkt.
4. Stoppen kan met Ctrl+C.

Niet dagelijks nodig:
- npm install
- npm run dev
- schema.sql opnieuw laden
- seed-demo-data.sql opnieuw laden

Belangrijk:
- server/config.local.php blijft lokaal en mag niet in Git.
- server/.php-path blijft lokaal en mag niet in Git.
- Het script gebruikt automatisch de map waar start-path-app.ps1 staat.
