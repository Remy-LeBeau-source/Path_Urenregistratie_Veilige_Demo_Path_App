Van wens tot oplevering

  1. Jira — vul rechts een wens in en klik "Start de flow". De wens wordt meteen aangenomen in de intakewachtrij; het issue met label pipeline-intake maakt de agent zelf aan.
  2. VS Code — de agent maakt het feature-bestand en de Playwright-case, draait de impactregressie en werkt de Living Doc bij (zie PIPELINE-INTAKE.md).
  3. Zephyr — de nieuwe case verschijnt in Testbeheer met techniek en assertions.
  4. CI en TEST — na een groene run staat het op uren-test.pathconsultancy.nl. De stap naar productie blijft een handmatige keuze.

Deze pagina toont de echte projectstand uit GIO-WENSEN.md en de feature-bestanden. "Simuleer de flow" is een korte animatie, geen echte testrun.
